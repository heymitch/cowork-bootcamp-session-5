# Cowork Bootcamp — Session 5: Landing Pages

Describe what you want. Your agent builds it and deploys it live.

## Install

Add the marketplace, then install the plugin:

```
/plugin marketplace add heymitch/cowork-bootcamp-session-5
/plugin install cowork-bootcamp-session-5@cowork-bootcamp-session-5
```

One install — both skills appear automatically.

## Skills

| Skill | Trigger | What It Does |
|-------|---------|-------------|
| Vercel Landing Page | "Build me a landing page for X" | Describe a page, get it deployed to a live URL |
| Frontend Design | "Design a page for X" | Create distinctive, production-grade frontend interfaces |

## Session Order

1. **Vercel Landing Page** — describe your page, watch it go live
2. **Frontend Design** — create custom designs that don't look like generic AI output
